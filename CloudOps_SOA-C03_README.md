# AWS CloudOps Engineer Associate (SOA-C03) Exam Prep

A collection of practice questions, answers, and supporting diagrams for the AWS Certified CloudOps Engineer Associate (SOA-C03) exam.

![Promotional image](images/promotional.png)

## 📄 Contents

### `CloudOps_SOA-C03_Questions.md`
Full question bank — **398 questions** with multiple-choice options (A–E), no answer key. Each question is a `## Question N` section; some include a diagram or policy-snippet image from the `images/` folder.

### `CloudOps_SOA-C03_Answers.md`
Answer key — **398 questions**, each with the question stem and the correct option(s) (some questions are "Choose two/three" and have multiple correct answers).

> The source material for this exam doesn't include worked explanations — only the correct choice(s) are marked, unlike the SAA-C03 answer file in the sister repo.

### `images/`
Diagrams, route tables, IAM policy snippets, and other visuals referenced by specific questions (e.g. `question1.jpg`, `question288_A.png`–`question288_E.png` for questions with a separate image per option). Keep this folder alongside both `.md` files so the image links resolve.
